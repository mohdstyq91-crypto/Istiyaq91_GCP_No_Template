Control Point Description

GCP Template Filler

Fill your Control Point Description templates automatically from Control.xlsx. Layout, logos and photos stay exactly as in your template.

Open the app
  • Runs in your browser
  • Many templates at once
  • Excel in, Excel out

How to use it

Five steps from Control.xlsx to filled templates.

  1. Open the app with the button above.
  2. Choose or drop Control.xlsx.
  3. Choose or drop one or more .xlsx templates.
  4. Pick how to fill: matched by GCP number, or every GCP from each template.
  5. Press Fill templates, then Download results.

Before you start

Get these ready first.

  • Templates must be .xlsx. Save old .xls files as Excel Workbook first.
  • Name each template with its GCP number, for example NS_JEEL_161.xlsx.
  • Control.xlsx needs GCP_No, Easting, Northing, Longitude, Latitude, Ellip_Height, Geoid_Separation and Ortho_Height (or Elevation).
  • You need internet access and a signed-in claude.ai account.

PDF output

Need PDFs instead?

The app creates Excel files. To make PDFs named after the GCP No, open the filled files in Excel and use File > Export > Create PDF/XPS.
